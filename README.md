# Pics2Text

将大量照片自动排版为指定文字，并支持曲面载体预览及超大印刷文件输出的平台。

项目当前处于规划阶段。

- [阶段文档索引](docs/progress/README.md)

## 技术基线

- Java 21
- Spring Boot 4.1.x
- Sa-Token（Spring Boot 4 Starter）
- MyBatis-Plus（Spring Boot 4 Starter）
- PostgreSQL
- Redis
- RabbitMQ
- S3 兼容对象存储（开发环境使用 MinIO）
- OpenCV + libvips
- React + TypeScript + PixiJS + Three.js
